B! ID

1つのメールアドレスで、
対応サービスにログイン

B! ID は、対応するサービスに同じメールアドレスでログインできる、無料のアカウントです。サービスごとにIDやパスワードを作る必要はありません。

できること

  • 対応サービスすべてに、同じメールアドレスでログインできます
  • パスワードは使いません。メールに届く認証コードだけで本人確認をします
  • 登録も利用も無料です

ご利用の流れ

  1. 対応サービスを開くと、ログイン画面に移動します
  2. メールアドレスを入力すると、6桁の認証コードが届きます
  3. 認証コードを入力すると、サービスに戻って使いはじめられます

はじめての方は、この手順の中で自動的に登録されます。別に登録する手続きはありません。

対応しているサービス

  • 株シミュレーター LIFE（テスト）B! IDログインの接続テスト用ページです。オンライン機能は準備中です。

取得する情報について

B! ID が取得して保存するのは、メールアドレスと登録日だけです。不要な個人情報は取得しません。

取得しないもの
パスワード、名前、写真、住所、電話番号、位置情報など
サービスに渡す情報
ふつうは、B! ID が発行する識別用のIDだけです。メールアドレスは、必要なサービスにだけ渡します。
認証コード
10分だけ有効で、1回しか使えません。5回間違えると無効になります。
ログインの有効期間
最大7日間です。期間が過ぎると、もう一度ログインが必要です。

よくある質問

認証コードのメールが届きません

迷惑メールフォルダをご確認ください。それでも届かないときは、1分ほど待ってから、もう一度「認証コードを送る」を押してください。メールアドレスの入力間違いもご確認ください。

別のスマホやパソコンでも使えますか

使えます。使いたい端末でサービスを開き、同じメールアドレスでログインしてください。

パスワードを忘れたときは

B! ID にパスワードはありません。ログインのたびに、メールで認証コードをお送りします。

登録した情報を消したいです

【ここに連絡先】までご連絡ください。ご本人のメールアドレスを確認したうえで、登録情報とログイン情報を削除します。
